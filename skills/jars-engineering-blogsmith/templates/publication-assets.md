## Claims to verify before publishing

- [ ] All repository links are public and correct
- [ ] PR status confirmed (open / merged / closed / draft)
- [ ] Version numbers accurate and up to date
- [ ] All commands tested on a clean environment
- [ ] No API keys, tokens, passwords, or internal URLs in article
- [ ] No private org names, internal project names, or customer data
- [ ] Test scope described accurately (unit ≠ integration ≠ end-to-end)
- [ ] LLM probabilistic behaviour acknowledged where relevant
- [ ] Architecture diagram source annotated (hand-drawn / AI-generated / from README)
- [ ] Demo link working and accessible
